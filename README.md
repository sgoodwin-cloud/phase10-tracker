# Phase 10 Tracker

A small, offline-friendly phone app for tracking who is on which phase in a game of Phase 10. One phone keeps track for the table. Plays our house rule: no points, first to complete Phase 10 wins.

Open https://sgoodwin-cloud.github.io/phase10-tracker/ in Safari, tap Share, then Add to Home Screen.
